# Data-sciene-load-explore
This project is implemented in the Python file **`codebook_data.py`**, which reads and displays structured user information stored in a JSON file. The program demonstrates how social network-like data, such as users, their friends, and liked pages, can be organized and processed using Python’s built-in `json` module. It focuses on understanding data handling in a clean and simple way.

The file contains two main functions: `load_data()` and `display_users()`. The `load_data()` function opens and loads the JSON file into a Python dictionary, while the `display_users()` function iterates through the users and pages to print their details in a readable format. This helps in understanding how lists and dictionaries work together in nested data structures.

Overall, `codebook_data.py` serves as a foundational project for learning file handling and structured data processing in Python. It builds essential skills that can later be extended to create features like friend recommendations, page suggestions, or even a complete mini social networking system.
